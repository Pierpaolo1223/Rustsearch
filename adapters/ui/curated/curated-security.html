Static search and untrusted text

A static index removes a whole class of server-side risk. There is no search endpoint to rate-limit, no query parser exposed to the network, and no server process that can be made to allocate an unexpected reply.

Text is inserted, never parsed

Titles, URLs, snippets and facet values are inserted with DOM text nodes. Highlight ranges are validated before they become markup, and a URL that is not a safe relative or http(s) link is shown as text.

The artifact is data

The .rsx file is read-only input. A corrupted artifact fails to load with an error instead of executing, because the loader validates the header, counts and version before serving a hit.

Deployment is a static host

Because the browser does the work, the origin only serves bytes. A CDN or object store is enough, and the same artifact can be published to several origins without a database to keep in sync.
