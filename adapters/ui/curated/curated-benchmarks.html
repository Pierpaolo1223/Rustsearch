What 10,000 documents means

This demo holds 10,000 indexed documents: 9,344 generated pages plus 656 split sections. The number in the footer is the document count, not the count of HTML files.

Artifact, not a database

The artifact on the wire is about 11 MB. It contains the dictionary, postings, document records and text needed for snippets. The browser loads it once; queries read it locally.

What the build spends

The build reads and analyzes every page before it writes anything. The result is immutable, so the expensive work happens at deploy time and never on a user's query.

What to measure next

Cold start is the cost of fetching and instantiating the WASM module; warm queries are the engine plus JSON. A serious demo should report both, on the same machine and the same corpus, instead of a single unlabeled number.
