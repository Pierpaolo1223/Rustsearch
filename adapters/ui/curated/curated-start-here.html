Start here: what this demo searches

This playground is a static full-text index over 10,000 documents built from the repository's Markdown. There is no database and no search server: the browser loads one immutable artifact and runs the same Rust engine that built it.

What is in the index

Each document is a section of a page. The build records an inverted index, BM25F statistics, facets for the section and language, and the text needed for snippets. A query only reads the artifact; it never crawls the site or calls an API.

Good queries to try

  • BM25F for ranking, title boost and score interpretation
  • facets for filters and facet counts
  • grouping for long pages split into several documents
  • typo for one-edit tolerance and its limits
  • artifact for the build and deployment model

Results are links, not a modal. The number in the footer is the count of indexed documents, not the number of HTML pages.
