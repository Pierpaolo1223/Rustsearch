Grouping a long page

A long page is indexed at paragraph granularity and presented at page granularity. Each chunk is a document with the same URL, title and facets, so a query can match the paragraph that answers it without making the reader open the whole page.

Why one page becomes documents

A page longer than the split threshold becomes several documents that share a URL. The artifact writes the title and URL once, and the record page keeps the page identity, so grouping does not need to fetch a string block.

What the option changes

With Group by page enabled, the best chunk represents the page and the others only raise its matches count. The limit counts pages, so pagination is not consumed by four paragraphs of one document.

When to turn it off

Turn grouping off when the question is about a section, not a page: then each chunk competes on its own score, and the snippet shows exactly the paragraph that matched.
