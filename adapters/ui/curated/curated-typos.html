Typo tolerance and one edit

Typo tolerance is opt-in. With Typo tolerance enabled, a query term can match a dictionary term one edit away: one insertion, deletion, substitution or adjacent transposition.

What counts as one edit

index can find indx and inxed; it cannot find a word two edits away. The fuzzy walk visits the sorted dictionary, so it costs more than an exact query and is off by default.

Why not always on

A one-edit match is a guess. On a short query it can pull in a common word that was never typed, so the exact result must stay first. The UI keeps fuzzy as an explicit control rather than hiding it in every search.

Title boost is separate

Typo tolerance decides which terms match; title boost decides how much a match in the title counts. They are independent arguments, and changing one does not change the other.
