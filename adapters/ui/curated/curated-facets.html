Facets and filters

A facet is a taxonomy the build records, not something the browser guesses. The demo indexes section and lang; the counts next to each value come from the artifact and update with the current query.

AND across fields, OR inside one

Selecting section=guide and section=reference returns pages from either section. Adding lang=en keeps only documents that satisfy both fields. Filters are resolved before ranking, so a filtered result list is still the top hits for the query.

Why filters matter

A user who knows the answer lives in operations should not have to read twenty hits from benchmarks. The facet counts also show when a filter would empty the result set, which is cheaper than running the search and discovering it later.

What is not a facet

Free text, snippets and ranking scores are per query. A facet must be stable across queries, or the counts would change with every keystroke.
